# FirstForm – Registration Form

## About
An Android registration form developed in Java using Android Studio for Mobile Application Development – Assignment 2.

## Features
- Username, full name, country, email, phone number and password
- Gender selection (Male/Female)
- Terms and conditions checkbox
- Create account button
- Registration details displayed in an AlertDialog
- Scrollable form using ScrollView

## Technologies
- Java
- XML
- Android Studio
